# AISummary Index

Ця папка містить короткі технічні підсумки (AI-summary) по окремих модулях.

## Принципи
- Один модуль = один файл.
- Нумерація: `0001_...`, `0002_...` у хронологічному порядку додавання.
- Мова: англійська (коротко, фактологічно).
- Формат: короткий опис призначення, ключові типи, залежності, правила, API, edge cases.

## Як оновлювати
- Якщо змінено публічний контракт модуля (API, типи, події) — оновити відповідний файл.
- Якщо додано новий модуль — створити новий `000X_*.md` файл.
- Узгоджувати з `Docs/ARCHITECTURE.md` і `Docs/STATUS.md`.

## Рекомендована структура файла
- Призначення
- Що входить
- Залежності
- Основні правила / інваріанти
- Події / реактивність
- API (коротко)
- Нотатки / edge cases
