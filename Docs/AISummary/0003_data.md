# AI Summary — Data (GridConfigSO)

## Purpose
`Data` contains authoring-time configuration assets, primarily ScriptableObjects.

## Main asset
- `GameData.GridConfigSO`
  - world params: `cellSize`, `originWorld`
  - bounds params: `minX`, `minY`, `width`, `height`
  - gizmo params: `draw`, `drawCellCenters`, `centerMarkerSize`

## Project status
- Includes `Data.asmdef` and a sample `Assets/Data/GridConfigSO.asset` in the repo.

## Cross-module links
- `Scenes.CompositionRoot` reads this asset to create `GridSettings` and initialize `GridService` + `PlacementService`.
- `Gameplay.Grid.GridGizmosRenderer` reads the same asset so editor visualization matches runtime grid configuration.
