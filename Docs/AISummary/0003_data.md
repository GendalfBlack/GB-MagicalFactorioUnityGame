## Data module — summary (GridConfigSO)

### What it contains
`Data` is a Unity assembly intended for *configuration & content assets* (ScriptableObjects), without gameplay/runtime logic.

Currently it provides:
- `GridConfigSO` — a ScriptableObject that stores grid parameters (cell size, origin, bounds) + gizmo toggles.
- `Data.asmdef` — assembly definition for the Data layer.

### Key dependencies
- Namespace: `GameData` (root namespace of the assembly).
- Assembly reference: `Core` (via GUID reference in `Data.asmdef`) so Data assets can be consumed by scene adapters that also talk to Core types.

### How it’s used
Typical usage is **scene-level adapters** (e.g., composition root / gizmo renderers) reading `GridConfigSO` to:
- initialize Core grid settings without hardcoding values,
- draw editor gizmos consistently with the same config.

### Scene / project wiring (minimal)
1. Create a `GridConfigSO` asset: **Assets → Create → Ritebound → Config → Grid Config**.
2. Assign this asset to systems that need grid settings (composition root, grid gizmo renderer, etc.).
3. Ensure the `Data` assembly is referenced where needed (note: `autoReferenced=false`, so you must reference it explicitly in consuming assemblies).

### Notes
- The provided files do **not** include a default `GridConfigSO.asset`. Create one in the project and set values per your level/world scale.
