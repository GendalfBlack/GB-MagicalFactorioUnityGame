# Devlog Index

Ця папка містить devlog-замітки для людей: що зроблено, які рішення прийняті, як працює API.

## Стиль
- Мова: українська.
- Тон: технічний, чіткий, без маркетингових формулювань.
- Структура: мета → залежності → ключові файли/типи → поведінка → інваріанти/обмеження → подальші кроки.
- Писати короткими блоками, з заголовками.
- Уникати зайвих деталей, які дублюють код без користі.

## Коли оновлювати
- Будь-яка зміна API, поведінки або залежностей модуля.
- Додавання нового модуля або важливого сценарію.

## Формат іменування
- Нумерація: `0001_...`, `0002_...` за порядком появи.
- Ім'я має відображати модуль або тему (наприклад, `core_grid_api`).
